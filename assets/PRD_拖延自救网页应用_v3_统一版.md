# CPTSD拖延自救网页应用 — 产品需求文档 v3（统一版）

> 一句话：卡住的时候打开它，走完一个结构化流程，10分钟内让你动起来。

---

## 一、架构总览

### 1.1 两层分工

```
┌──────────────────────────────────────────────────────────┐
│                    拖延自救网页应用                         │
│                                                          │
│  网页应用层（扣子结构化UI）                                  │
│  职责：结构化步骤引导、按钮/填空/计时器、感官干预              │
│  处理次要矛盾：注意力耗竭、时间盲症、身体冻结                   │
│                                                          │
│  ───────────── Chat SDK 悬浮窗 ─────────────              │
│  智能体层（AI对话）                                         │
│  职责：内在批判者识别+驳斥、RSD命名、复盘分析                  │
│  处理主要矛盾：内在批判者+毒性羞耻感                           │
│                                                          │
│  ↕ 共享状态：localStorage (key: cptsd_app_state)          │
└──────────────────────────────────────────────────────────┘
```

### 1.2 干预顺序

身体着陆(降低杏仁核) → AI驳斥批判者(打击主要矛盾) → 结构化行动(前额叶恢复后执行)

### 1.3 核心原则

- 用户永远不需要打字问问题。每一步都是按钮选择 + 短填空
- 单页应用，一个屏幕走完，不翻页
- 方法按效果强度排序，最强推荐放最前面
- 不评判干预效果，用身体信号确认替代效果评判

## 二、用户流程主干

### 2.1 入口分流（第1屏）

标题：你现在什么情况？

4个大按钮竖排：

| 按钮 | 对应模式 | 流程长度 |
|:---|:---|:---|
| 🍳 日常小事拖沓 — 做饭、洗衣不想做 | 快速模式 | 3步，3分钟 |
| 🧠 大脑突然空白 — 脑子空了不想动 | 重启模式（感官优先） | 3步，2-3分钟 |
| 📱 注意力被拐跑 — 刷了太久手机 | 快速模式 | 3步，3分钟 |
| 🏔️ 重要的事一直拖着 — 找工作、发作品 | 完整模式 | 7步，10-15分钟 |

**设计逻辑**：
- A/C → 快速模式（日常低认知负荷场景，不需要深度诊断）
- B → 重启模式（僵反应状态，不做填空，只做身体动作）
- D → 完整模式（重要课题，需要完整SOP诊断）

## 三、前置模块：能量评估（所有模式共用）

**位置**：每个模式的第一步（除非跳过的场景）。
**耗时**：3秒。
**目的**：防止用户在红色日强行走完完整流程，导致耗竭和更深自责。

### 3.1 交互

3个大按钮横排：

```
┌─────────────┬─────────────┬─────────────┐
│  🔴 红灯    │  🟡 黄灯    │  🟢 绿灯    │
│  特别累     │  有点累     │  有精神     │
└─────────────┴─────────────┴─────────────┘
```

### 3.2 各能量级的流程映射

| 评级 | 身体信号（用户自检） | 流程决策 |
|:---|:---|:---|
| 🔴 红灯 | "连起床/起身都觉得费劲" | 走**简化流程**：不做填空诊断，只做最小身体动作 + AI驳斥批判者。完整模式的Step 1-4全部跳过 |
| 🟡 黄灯 | "可以，但需要逼自己一下" | 走**标准流程但降低标准**：所有步骤60分即可进入下一步。注意力节律自适应（10+2而非25+5） |
| 🟢 绿灯 | "没问题" | 走**完整流程**：早晨第一件事是身体动作而非思考，暴露性任务优先 |

### 3.3 CPTSD特定能量降级触发（知识库用，不展示给用户）

与ADHD不同，CPTSD的能量降级有心理触发源：
- 情绪闪回后遗症（即使没意识到）
- 内在批判者攻击日（从醒来就在自我攻击）
- 高暴露事件前后（即将发布/投递/面试→能量被提前透支）
- 感官透支（前一天过度社交/高强度输入）

## 四、模式A/C：快速模式（3步，3分钟）

适用入口：日常小事拖沓（A）+ 注意力被拐跑（C）。

### 步骤1/3：能量快评

见前置模块（第三节）。红灯 → 直接跳到步骤3（最小动作）。
流程C特殊：红灯时增加注意力回收（10秒窗外注视）再跳到步骤3。

### 步骤2/3：注意力回收（仅流程C）

**交互**：10秒倒计时（大号数字，SVG圆环动画）。

引导文字："看窗外10秒钟，找到你能看到的最远的东西，盯着它看。"

倒计时结束 → 输入框（一行）："你本来要做的事是什么？"

### 步骤3/3：最小动作

输入框（最大100字）："这件事最小的第一步是什么？不用完整计划，就第一步。"

**闹钟提示**：
"在手机上设5分钟闹钟。闹钟响之前只做这一件事。闹钟响了就可以停下来。"

按钮：✅ 闹钟设好了，开始！

### 完成页

见第十节（通用完成页）。

## 五、模式B：重启模式（3步，2-3分钟）

适用入口：大脑突然空白（僵反应/唤起不足）。

**神经状态**：hypo-arousal——背侧迷走神经过度激活，代谢崩溃式"关机"。
**干预目标**：用感官刺激激活神经系统，把身体从关机状态拉回耐受窗口。

### 步骤1/3：能量快评

同第三节。但此时用户可能无法做选择——如果3秒内无反应，自动默认为红灯。

### 步骤2/3：身体激活（不做填空，核心步骤）

标题："你的大脑没有坏——它只是暂时关机了。我们先唤醒身体。"

**6个按钮分三排，按通路分组：**

**第一排：冷通路（潜水反射——最快但需要道具）**

| 按钮 | 交互 | 时长 |
|:---|:---|:---|
| 🧊 冰块贴脸+屏息（★推荐） | 引导：包冰→贴脸颊/后颈→屏息15秒→拿下→深呼吸。倒计时进度条 | 15-30秒 |
| 💧 冷水冲脸+屏息 | 引导：冷水拍脸10次（屏息）→擦干→深呼吸。倒计时 | 10-15秒 |

**第二排：迷走通路（零道具，高敏感者优先）**

| 按钮 | 交互 | 时长 |
|:---|:---|:---|
| 🎵 哼唱/voo声 | 引导：深吸→低沉"voo——"拉长→感受振动→重复3次 | 15-30秒 |
| 👀 环境定向 | 引导：慢转头向左→扫视→慢向右→扫视→回中→"这里有危险吗？" | 30秒 |

**第三排：运动通路（需要起身，但不需要道具）**

| 按钮 | 交互 | 时长 |
|:---|:---|:---|
| 🤲 抖掉/Shake it out | 引导：站起→手腕轻抖→扩展到全身→30秒→停→深呼吸 | 30-60秒 |
| 🚶 出门走5分钟 | 引导：直接出门→走5分钟→看远处→不设目标 | 5分钟 |

**底部兜底提示**（小字）："手放胸口，感受手掌的温度和呼吸的起伏——任何时候都可以做。"

### 步骤3/3：最小确认 + 状态检查

标题："你刚才做了身体动作。这已经是'做了什么'。"

两个按钮：
- 🔄 我感觉好些了，回到首页
- 💬 还是动不了，和疗愈助手聊聊

选择"和疗愈助手聊聊"→ 自动展开Chat SDK，传递当前状态（energyLevel: "red", mode: "restart_stuck"）。

### 完成页

见第十节。

## 六、模式D：完整模式（7步，10-15分钟）

适用入口：重要的事一直拖着。这是核心流程，覆盖原SOP + 感官升级 + 时间管理。

### Step 0：能量评估 + 感官着陆

**交互顺序**：
1. 上半区：🔴/🟡/🟢 三选一（见第三节）
2. 下半区：根据能量级别进入不同分支

#### 绿灯分支：完整感官着陆（预防性维稳）

标题："状态不错。花1分钟做个感官着陆——在杏仁核被激活之前先巩固安全感。"

**4个短干预，用户任选或跳过**：

| 选项 | 操作 | 时长 |
|:---|:---|:---|
| 👁 视觉着陆 | 找5个不同颜色的东西，心里念出来 | 30秒 |
| 🤚 触觉着陆 | 手触碰3个不同质地的东西 | 30秒 |
| 🌬 呼吸着陆 | 吸气4→憋2→呼气6，重复3次。呼吸动画球 | 30秒 |
| 🎵 Voo声着陆 | 深吸→"voo——"拉长→感受振动 | 30秒 |

按钮：**准备好了，开始 →**（进入Step 1）

#### 黄灯分支：5步混合流程（身体介入→AI驳斥→微动作）

**H1 - 身体介入（1-2分钟）**

标题："先给神经系统一个'安全'信号。三条通路，选一个你能做的："

**6个按钮按通路分组，同模式B（去掉出门散步，增加延长呼气）：**

| 通路 | 按钮 |
|:---|:---|
| 冷通路 | 🧊 冰块贴脸+屏息（★推荐）、💧 冷水冲脸+屏息 |
| 迷走通路 | 🎵 哼唱/Voo声、🌬 延长呼气呼吸（吸4呼6，5轮） |
| 运动通路 | 👀 环境定向、🤲 抖掉+手放胸口 |

做任一动作后 → 显示确认："你刚才做了一个身体动作。杏仁核的警报音量已经调低了。"

**H2 - AI驳斥批判者（2分钟）**
自动展开Chat SDK，传递上下文："用户当前能量：黄灯。请帮用户识别和驳斥内在批判者。"
下方提示文字："和疗愈助手聊完后，点击下方按钮继续 →"

**H3 - 能量分配**
"你现在大概还剩多少力气？"
3个按钮：够2分钟 | 够5分钟 | 够10分钟
（不设超过10分钟的选项）

**H4 - 微动作执行**
输入框："接下来X分钟，你只做这一件事：______"
大号倒计时显示 + 闹钟提示

**H5 - 快速收束**
按钮：[ 我动了！] → "你动了。不管做了多少。现在去休息。"
按钮：[ 没动…… ] → "没关系。休息也是需要的。想聊聊为什么没动，点右下角疗愈助手。"

#### 红灯分支：简化流程（不做填空）

弹出提示卡片："你的神经系统现在需要休息，不是push。我们只做三件最小的事："

**R1 - 身体信号确认**（不填空，只是引导注意）
"感受一下：肩膀是紧还是松？手是冷还是热？呼吸是浅还是深？"
按钮：**感觉到了**

**R2 - AI驳斥批判者**
输入框："你脑子里最响的那句自我批评是什么？"
填完后 → [ 告诉疗愈助手 ] → 自动展开Chat SDK，传递自我批评内容供驳斥。

**R3 - 最小休息动作**
两个选项：[ 🧊 做一个身体重置 ] → 引导做冰块贴脸/冷水洗脸
[ 🌙 我就是需要休息 ] → "休息也是行动。你不必证明自己'配休息'。"

完成后直接到完成页（不进入Step 1-4）。

### Step 1：锁定目标 + 恐惧（2分钟）

**问题1**：输入框（最大50字）"你一直拖着没做的事是什么？一句话。"

**问题2**：输入框（最大100字）"真正要做的时候，你最怕发生什么？不是'怕做不好'——具体一点，最怕的结果是什么？"

**RSD命名触发**：如恐惧内容包含"被否定/被嘲笑/被拒绝"类关键词 → 在输入框下方显示信息卡片：

```
┌────────────────────────────────────┐
│ 💡 这个感受有一个名字               │
│                                     │
│ 叫「拒绝敏感性焦虑」(RSD)。          │
│ 它不是事实，是你大脑的过度保护程序。  │
└────────────────────────────────────┘
```

按钮：**继续 →**

### Step 2：写准备动作（2分钟）

"把脑子里'我得先做XX'的念头写下来。不评判，先写。"

动态列表：初始1个输入框，可点"＋ 再加一条"添加（最多4条）。

**自动检测条数**（用户写完"确认"后）：
- ≤ 2条 → "好，我们逐条来看。"
- 3-4条 → "有点多了。选最重要的2条。其余的做完这件事再回头看。"

筛选界面：每条旁有复选框。超过2条无法勾选。

**设计逻辑**：强制限制2条是防止ADHD用户因选择过多而宕机（来自产品验证审查报告结论）。

按钮：**确认，开始诊断 →**

### Step 3：四象限诊断（3分钟）

逐条显示。每条占一个卡片：

```
┌──────────────────────────────────────┐
│ 准备动作 1/2： 「学排版工具」           │
│                                       │
│ 问题1：做这件事，心里是——              │
│  [ 我愿意 ]    [ 我必须 ]              │
│                                       │
│ 问题2：做完之后，心里冒出的是——         │
│  [ 可以继续了 ]  [ 还不够 ]            │
└──────────────────────────────────────┘
```

用户选完后，自动判断象限：

| 象限 | 规则 | 处理 |
|:---|:---|:---|
| ✅ 真正推进 | 我愿意 + 可以继续了 | "保留，正常做。" |
| 🟡 精致拖延 | 我愿意 + 还不够 | "做完目标动作后再回头做。先记录下来。" |
| 🟠 带着怕做 | 我必须 + 可以继续了 | "简化到够用就行。最简版本是什么？" |
| 🔴 假装在忙 | 我必须 + 还不够 | "和目标没有关系，先删掉。" |

诊断完成 → 显示汇总卡片（保留几条、删除几条）。

按钮：**继续 → 设定时间**

### Step 4：行动启动（3分钟）

**子步骤1：多巴胺预热**

"先做一个小动作热个身。跟你的目标有关，但简单到不可能失败。"

3个快捷按钮（根据目标动作类型动态显示不同建议）：
- 写作类："打开编辑器，打一行字'我接下来要写的是……'"
- 求职类："打开招聘网站首页（不筛选，就看一眼）"
- 发布类："把文档从桌面拖到发布文件夹里"

输入框（用户自己写也可以）。

**子步骤2：设定时间窗**

| 开始时间 | 结束时间 |
|:---|:---|
| [时间选择器] | [时间选择器] |

默认值：当前时间 + 30分钟。

行动内容：多行文本框，预填Step 3汇总的保留条目。

**子步骤3：闹钟提示（时间外化——必填）**

大号醒目提示：

```
⏰ 现在，在手机上设一个闹钟

不设闹钟的话，时间盲症会让你在"再过一会儿"中
耗掉整个下午。

设好了再点继续。
```

按钮：✅ 闹钟设好了！

**子步骤4：视觉计时器**

"把手机倒计时打开，放在你能看到的地方。让时间'可见'。"

页面内显示倒计时（大号数字），从设定的时长开始倒数。

按钮：▶️ **开始行动**

#### 行动中审视："我卡住了"按钮（始终悬浮）

右下角悬浮按钮：🆘 **我卡住了**

点击后弹窗——**三级分支判断**：

```
┌───────────────────────────────────────┐
│ 你怎么卡住的？                         │
│                                       │
│ [ 💭 脑子里冒出新想法 ]                │
│ [ 🫂 身体动不了 ]                      │
│ [ ⏰ 时间感知/精力问题 ]（新增）         │
└───────────────────────────────────────┘
```

**分支1：新想法** → 回到Step 3快速诊断（1分钟，单条）。
自动发上下文给AI："用户行动中冒出新想法：___。请快速判断。"

**分支2：身体动不了** → 触发感官着陆（不做诊断）。

"身体动不了不是你的错——是杏仁核把'行动'识别成了'威胁'。先帮身体确认安全："

3个选项（同模式B的三通路）：
- 🧊 冰块贴脸+屏息15秒（★推荐）
- 🎵 Voo声+呼吸（零道具温和方案）
- 🤲 手放胸口（最基础的自我安抚）

完成后：按钮 [ 感觉到了一点，继续行动 ] / [ 今天够了，去休息 ]

**分支3：时间感知/精力问题（新增）**

"你现在处于哪个阶段？"（匹配日循环四阶段模型）

3个按钮：
- 🌀 注意力散了，一直分心 → **环境降噪提示** + "试试10分钟专注+2分钟休息的节奏"
- 😴 身体耗尽了，大脑发酸 → **休息提示** + "这不是懒，是神经系统需要恢复。设15分钟闹钟，闹钟响了再决定要不要继续。"
- ⏰ 截止线太远/太近感知不到 → **时间外化提示** + 重新设闹钟 + 用微时间盒（5分钟或10分钟）

### Step 5：复盘（2分钟）

**问题1**：输入框"你原本预期会发生什么？"
**问题2**：输入框"实际发生了什么？"

**自动判断结果**（三种卡片）：

实际比预期好 → 🟢 绿色卡片：
"大脑骗了你！你之前X次行动，Y次结果都比预期好。你的大脑Z%的时候都在骗你。这次也是。"

实际和预期差不多 → 🔵 蓝色卡片：
"和你想的差不多。但你处理了。比你以为的更有能力。"

实际比预期差 → 🟡 黄色卡片：

## 八、UI规范

### 8.1 统一布局

```
┌─────────────────────────────────────┐
│  🧊 拖延自救启动器                   │
│  卡住的时候打开，10分钟让你动起来     │
├─────────────────────────────────────┤
│                                     │
│   [当前步骤内容区域]                 │
│   - 提示文字（简洁，≤2行）            │
│   - 输入框 / 按钮组                  │
│   - 上一步 / 下一步                  │
│                                     │
├─────────────────────────────────────┤
│  ● ● ● ○ ○ ○ （进度条）            │
│  ⚠️ 这不是心理咨询，你随时可以停下    │
└─────────────────────────────────────┘
```

### 8.2 设计要点

- 单页应用，一个屏幕走完，不翻页
- 只显示当前步骤，不露出后续步骤（降低认知负担）
- 配色：米白底(#FAFAF9) + 深灰字(#2D2D2D) + 浅蓝按钮(#4A90D9)
- 危险提示用浅红(#E8A0A0)，不用正红
- 手机端优先（max-width: 480px）
- 每步间淡入动画 300ms
- 按钮点击有微缩放 transform: scale(0.97)
- 输入框获得焦点时不改变页面布局
- "我卡住了"按钮始终悬浮在右下角
- 安全提示始终固定在底部
- Chat SDK悬浮窗不遮挡主要操作按钮

### 8.3 黄灯/红灯特殊UI规则

- **黄灯**：所有文字量减半（黄灯用户阅读能力下降）
- **红灯**：只显示必要元素，其余隐藏。不设"跳过"选项（让用户觉得"可以跳过"也是一种认知负担）
